CONECTA TUS SISTEMAS

Una API. Todo tu espacio.

CRUD de archivos y carpetas mediante HTTPS. Usa un token de lectura o administración desde tu integración.

Los tokens se generan en .env.api. Esta interfaz no los recibe ni los almacena en el navegador.

  • GET /v1/files — listar
  • GET /v1/content — descargar
  • PUT /v1/content — subir o reemplazar
  • POST /v1/directories — crear carpeta
  • PATCH /v1/entries — mover o renombrar
  • DELETE /v1/entries — eliminar

Consulta API.md para ejemplos, límites y rotación.
